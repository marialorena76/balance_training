# Balance Training Academy — Landing de cursos

Landing de venta + página de detalle de curso para **Balance Training Academy**
(extensión visual de https://balancetrainingacademy.com.ar).

## Estructura
- `index.html` — Landing de venta (página principal)
- `curso.html` — Detalle del curso "Fundamentos del Balance Training"
- `styles.css` — Tokens y estilos (paleta marrón/tostado/dorado + salvia, tipografía Raleway)
- `shared.jsx` — Navbar, footer, logo, datos de contacto, utilidades
- `landing.jsx` — Secciones de la landing
- `curso.jsx` — Secciones del detalle de curso

Hecho con React + Babel vía CDN. No requiere build: son archivos estáticos.

## Cómo verlo / publicarlo
**Local:** abrí `index.html` en el navegador (o serví la carpeta con cualquier servidor estático).

**GitHub Pages:** Settings → Pages → Branch `main` / carpeta `/ (root)`.
La página de inicio será `index.html`.
